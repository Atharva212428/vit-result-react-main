# VIT Semester Result Calculator (React)

Calculates semester results for 4 subjects using MSE (30%) + ESE (70%) weightage.

## Tech: React, Vite, CSS Grid

## Subjects
- CS3212: Design and Analysis of Algorithm (4 credits)
- CS3213: Computer Networks (3 credits)
- CS3212A: Web Technologies (4 credits)
- MM0701B: Ethical Hacking (3 credits)

## Run
npm install
npm run dev
